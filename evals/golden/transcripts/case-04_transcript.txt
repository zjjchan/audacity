### Is this bug reproducible in Audacity 4?
No

### Bug description
Snap to CDDA frames (75 fps) does not work in 3.7.9. It actually hasn't worked for a long time. All the other 'Snap' options work just fine. 

### Steps to reproduce
1. Open an audio file.
2. Click on Snap checkbox
3. Select CD frames > CDDA frames (75 fps)
4. Try to select a range in the waveform and it will just allow you to select anything. It doesn't snap to the proper frames, so exported files will almost always have an SBE error when burning to a disc. This used to work. Not anymore. Not sure which 3.x update broke it.

### Expected behavior
The waveform selection should snap to the next CDDA frame

### Actual behavior
It just allows me to select whichever part, so cuts/edits don't align with CDDA frames

### Audacity Version
Audacity 3.7.9

### Operating system
Windows
